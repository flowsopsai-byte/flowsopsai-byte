## Current project

**[Lead Rescue](https://github.com/flowsopsai-byte/lead-rescue)** — missed-call
recovery for local trades. An unanswered call triggers an SMS, an AI
qualification chat, a scored summary in the owner's CRM, and a daily audio
briefing. Multi-tenant on Supabase, orchestrated in n8n, dashboard in Next.js.

## Stack

OpenAI and Anthropic APIs · Cartesia and ElevenLabs for voice · Typebot ·
Telnyx · HubSpot
